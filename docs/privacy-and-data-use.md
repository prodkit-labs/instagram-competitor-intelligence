# Privacy and Data Use

This project is designed for public-data reporting workflows.

## What This Project Does

- works with public profile-style data
- analyzes public posts and Reels-style media records
- calculates reporting metrics
- generates Markdown, HTML, and CSV-friendly outputs
- supports mock data for local development and documentation

## What This Project Does Not Do

- does not require Instagram passwords
- does not collect private account data
- does not automate likes, follows, comments, or DMs
- does not claim affiliation with Instagram, Meta, or any provider
- does not provide tools for fake engagement or spam workflows

## Data Storage

The starter project uses local files and sample datasets.

If you adapt it for production, document where data is stored, who can access it, and how long it is retained.

Do not commit API keys, `.env` files, access tokens, private account data, or provider credentials.

## Public-Data Boundary

This project is intended for analysis of publicly available information and reporting workflows.

Always review the terms, laws, and policies that apply to your use case, provider, customer, and jurisdiction.
