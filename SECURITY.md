# Security Policy

## Credentials

Do not commit API keys, access tokens, provider credentials, private account data, or environment files.

Use `.env` for local development and repository secrets for GitHub Actions.

## Intended Use

This project is designed for public-data reporting workflows.

It should not be used for:

- collecting private account data
- storing Instagram passwords
- automating likes, follows, comments, or DMs
- fake engagement
- spam workflows
- account automation

## Reporting Security Issues

If you notice a security issue in this repository, please open an issue without including sensitive credentials or private data.
