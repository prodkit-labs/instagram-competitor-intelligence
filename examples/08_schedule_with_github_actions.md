# Schedule With GitHub Actions

This project includes `.github/workflows/weekly-report.yml` as a starting point.

Before enabling it:

1. Add `HIKERAPI_KEY` as a GitHub Actions repository secret.
2. Set `INSTAGRAM_DATA_PROVIDER=hikerapi` in the workflow environment.
3. Confirm your API usage and cost expectations.
4. Keep the workflow focused on public data analysis and reporting.

The default workflow runs with mock data so new users can test the project safely.
